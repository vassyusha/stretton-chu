# stretton-chu

Численный расчёт электромагнитного поля в фокусе параболического зеркала
по интегралам Стреттона-Чу (приближение идеального проводника, система СГС).

Падающая волна: плоская, линейно поляризованная вдоль оси `y`,
распространяется вдоль оптической оси (против оси `x`). Фокус зеркала
находится в начале координат.

## Возможности

- Интегралы Стреттона-Чу в **декартовых** координатах (интегрирование по кругу).
- Те же интегралы в **параболических** координатах
  (круг переходит в прямоугольник, `x = (τ² − 2f₀)/2`, `y = √(2f₀)·τ·cosφ`,
  `z = √(2f₀)·τ·sinφ`, якобиан `τ` учтён в подынтегральной функции).
- Методы интегрирования по двумерной области `y₁(x) ≤ y ≤ y₂(x)`:
  метод трапеций, метод ячеек (проверка по центру и по углам).

## Структура

| Файл | Назначение |
|---|---|
| `src/Vector.hpp` | трёхмерный вектор |
| `src/Constants.hpp` | π и скорость света (СГС) |
| `src/Solver.{hpp,cpp}` | численное интегрирование |
| `src/Cartesian.hpp` | подынтегральные выражения, декартовы координаты |
| `src/Parabolic.hpp` | подынтегральные выражения, параболические координаты |
| `src/main.cpp` | тестовый расчёт: сравнение двух систем координат |

## Использование

```cpp
#include "Cartesian.hpp"
#include "Parabolic.hpp"

// k, E0, f0, r_m, psi0
Parabolic mirror(k, e0, f0, rm, psi0);

Vector3 E = mirror.integrateE(Vector3(0, 0, 0), /*time=*/0.0, /*n=*/1000, /*m=*/1000);
Vector3 H = mirror.integrateH(Vector3(0, 0, 0), 0.0, 1000, 1000);
```

`Cartesian` имеет тот же интерфейс. Область интегрирования и интегратор
выбираются внутри классов.

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build
./build/stretton_chu [N]     # N - число узлов по каждой переменной, по умолчанию 1000
```

Без CMake:

```bash
g++ -std=c++17 -O2 -Isrc src/*.cpp -o stretton_chu
```

## Параметры тестового расчёта

`r_m = 0.01 см`, `f₀ = 2r_m` (f# = 1), `λ = 10⁻⁴ см`, `ψ₀ = π/2`,
`E₀ = √(2·10²² / (c·r_m²)) ≈ 8.17·10⁷` (мощность порядка 0.5 ПВт).

Ожидаемые значения (N = 1000, t = 0):

| Точка | Поле | Значение |
|---|---|---|
| (0, 0, 0) | E_y ≈ H_z | ≈ 1.2075·10¹⁰ |
| (0, 0.5λ, 0.5λ) | E_z ≈ H_y | ≈ 1.0339·10⁸ |
